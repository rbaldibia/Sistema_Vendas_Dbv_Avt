# Sistema de Vendas Dbv & Avt

App web criado para vendas de campanhas dos Clubes de Desbravadores e Aventureiros. Um sistema simples e prático de usar, com toda a infraestrutura necessária para fazer as vendas e acompanhamentos do início ao fim.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias:

- [React](https://reactjs.org) (v18)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [React Router DOM](https://reactrouter.com/)
- [Lucide React](https://lucide.dev/) (Ícones)

## 💻 Instalação e Execução

Siga os passos abaixo para executar o projeto em sua máquina local:

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18+ recomendada)
- NPM ou Yarn

### Passo a passo

1. **Acesse a pasta do projeto**:
   ```bash
   cd project
   ```

2. **Instale as dependências**:
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento**:
   ```bash
   npm run dev
   ```

4. O aplicativo estará disponível no seu navegador, geralmente no endereço `http://localhost:5173`.

## 📖 Uso

Após iniciar a aplicação, você terá acesso ao painel principal. O sistema permite:

- Cadastrar novos produtos para as campanhas.
- Registrar as vendas realizadas pelos membros (Desbravadores ou Aventureiros).
- Acompanhar o progresso das metas financeiras e gerar relatórios básicos.
